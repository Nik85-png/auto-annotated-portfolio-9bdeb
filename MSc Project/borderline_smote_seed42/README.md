# BorderlineSMOTE seed 42 experiment

This folder is a non-destructive copy of the MSc Project modelling pipeline for the BorderlineSMOTE experiment.

Files here only change the imbalance handling in:
- `02_preprocessing.py`
- `03_modelling.py`

The original `MSc Project` scripts are left untouched.

Use the Colab notebook in this folder to copy the project into a runtime workspace and run the experiment.
